# Cube of Spheres Showcase

A standalone static gallery for the Cube of Spheres material and animation studies.

## Preview locally

From this folder:

```sh
python3 -m http.server 4174
```

Then open `http://localhost:4174`.

## Publish

The entire folder is deployable as-is to any static host, including Netlify, Vercel,
GitHub Pages, or Cloudflare Pages. No build command is required.
